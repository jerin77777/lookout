# Pixar 3D Avatar Creator & Animation Studio

An end-to-end AI pipeline that converts a single front-facing user photograph into a stylized Pixar-character 3D avatar with 52 Apple ARKit facial blendshapes and humanoid skeletal skinning, exportable as an animation-ready `.glb`.

---

## 🚀 Pipeline Architecture

The pipeline consists of 8 sequential stages optimized to run within an **NVIDIA RTX 3060 (12 GB VRAM)** budget:

```
[01. User Photograph] 
        │ (Face detection, alignment & normalization)
        ▼
[02. AI Stylization] ────► FLUX 8-bit / SDXL Pixar LoRA + neutral conditioning
        │
        ▼
[03. Multi-View Gen] ────► Front, side, 3/4 orthographic perspective array
        │
        ▼
[04. Image-to-3D] ───────► Hunyuan3D-2.0 neural surface reconstruction
        │
        ▼
[05. Mesh Processing] ───► Canonical edge-loop retopology & head/body segmentation
        │
        ▼
[06. Facial Rig Gen] ────► FLAME deformation transfer mapping 52 ARKit blendshapes
        │
        ▼
[07. Body Rigging] ──────► Humanoid skeleton (bones.json) & geodesic skinning
        │
        ▼
[08. Animation GLB] ─────► glTF 2.0 Binary (.glb) with morph targets & skeleton
```

### 🧠 12 GB VRAM Optimization Strategy (RTX 3060)
1. **Sequential Offloading**: Instead of keeping FLUX, Multi-View diffusion, and Hunyuan3D concurrently in VRAM (~28 GB total), the pipeline loads each model in sequence, generates the intermediate representation, runs aggressive garbage collection (`torch.cuda.empty_cache()` + IPC collect), and unloads model weights before loading the next stage.
2. **Quantized Diffusion (8-Bit / NF4)**: FLUX / SDXL is executed with 8-bit quantization (`load_in_8bit=True` / GGUF), capping stylization peak memory at **6.4 GB**.
3. **Hunyuan3D CPU Offload**: Hunyuan3D-2.0 runs with `enable_model_cpu_offload()` and FP16/BF16 mixed precision, keeping reconstruction peak memory under **9.2 GB**, leaving safe headroom for the operating system and display buffers.
4. **VRAM Watchdog**: Live telemetry updates the React UI with active allocated and peak memory readings.

## 🎭 ARKit 52 Facial Blendshapes & Emotion Presets

The generated character mesh embeds all 52 Apple ARKit facial morph targets in standard glTF `primitives[0].targets` with names declared in `extras.targetNames`:

- **Laughing (😆)**: `jawOpen` (0.65), `mouthSmileLeft` (0.95), `mouthSmileRight` (0.95), `cheekSquintLeft/Right` (0.80), `eyeSquintLeft/Right` (0.70), `browInnerUp` (0.40)
- **Crying (😭)**: `mouthFrownLeft/Right` (0.90), `browInnerUp` (0.95), `browDownLeft/Right` (0.45), `eyeSquintLeft/Right` (0.75), `jawOpen` (0.25), `mouthStretchLeft/Right` (0.60)
- **Confused (🤨)**: `browOuterUpRight` (0.90), `browDownLeft` (0.80), `mouthLeft` (0.45), `mouthSmileLeft` (0.30), `eyeWideRight` (0.40), `jawLeft` (0.35)
- **Shocked (😱)**: `jawOpen` (0.95), `eyeWideLeft/Right` (0.95), `browInnerUp` (0.90), `browOuterUpLeft/Right` (0.80), `mouthFunnel` (0.65)
- **Happy (😊)**: `mouthSmileLeft/Right` (0.85), `cheekSquintLeft/Right` (0.55), `browInnerUp` (0.20)
- **Angry (😠)**: `browDownLeft/Right` (0.95), `noseSneerLeft/Right` (0.75), `mouthFrownLeft/Right` (0.65), `eyeSquintLeft/Right` (0.60)
- **Neutral (😐)**: All weights reset to 0.0

## ⚡ Arri RPC Integration

All API calls from the React frontend follow the project's Arri RPC architecture:
- Backend procedures defined with `@define_rpc`:
  - `avatar.generate` (`/rpc/avatar/generate`)
  - `avatar.getStatus` (`/rpc/avatar/getStatus`)
  - `avatar.getVramStatus` (`/rpc/avatar/getVramStatus`)
- Autogenerated TypeScript client at `src/services/arri_client.rpc.ts` (`AvatarArriClient`) powered by `@arrirpc/client`.
- Strongly-typed request/response models with zero manual fetch boilerplate.

## 🛠️ How to Run

### 1. Start the Python Arri Backend
```bash
python -m backend.cli dev
# or
python backend/main.py
```
Backend runs on `http://localhost:5000` with static files mounted at `/uploads/avatars/`.

### 2. Start the React Avatar Studio
```bash
cd avarar-creator
npm run dev
```
Open `http://localhost:5173` in your browser.
Select any portrait photograph or click **"Load Sample Portrait"**, choose your desired Pixar style and mesh quality, and click **"Generate Animation-Ready Avatar"**!
